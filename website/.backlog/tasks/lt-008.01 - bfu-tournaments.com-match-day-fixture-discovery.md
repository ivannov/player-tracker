## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Given a competition + date (or 'all competitions' + date), discover which matches were played/scheduled that day and return each match's bfu-tournaments.com page URL plus the two team names (whatever else the listing page cheaply exposes, e.g. status/score preview). This is the missing piece the LT-008 stub flags: BfuMatchScraperService (LT-007.01) only scrapes an already-known match URL, and BfuLeagueScraperService (LT-001.01) only lists a league's teams, not a schedule -- neither can answer 'what happened on date X'. Mirror the existing Jsoup + checked-exception + fixture-based-test pattern (BfuLeagueScraperService / BfuMatchScraperService). Needs real recon against bfu-tournaments.com to find the actual competition+date listing page structure before writing the parser (see experiences/bfu-scraping for the recon-workaround pattern used for LT-007.01/LT-006.01).
