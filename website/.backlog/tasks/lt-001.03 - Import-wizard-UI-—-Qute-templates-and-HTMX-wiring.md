## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build the Qute templates and HTMX interactions for the three-step participation import wizard (LT-001). Backend endpoints provided by LT-001.02.

**Step 1 — `templates/ParticipationImportResource/step1.html`**
Full page (extends layout). Inputs: URL text field, competition `<select>` (from DB), season text field (placeholder `2024/2025`). Submit: `hx-post="/participations/import/extract"` → swaps `#wizard-body`.

**Step 2 — `templates/ParticipationImportResource/step2.html`** (HTMX partial, no layout)
One row per scraped team:
- Scraped name as read-only label
- Team picker: `<input list="teams-list">` + `<datalist id="teams-list">` with all DB teams (value=id, label=name) — native browser search, no JS library needed. Hidden `teamId` field synced via small inline script on input change.
- "New team" toggle: reveals name + location inputs, hides the datalist picker
- Formation picker: `<select>` of FormationTypes; on team selection fires `hx-post="/participations/import/formations"` to swap in only that team's existing formations + "add new formation" option
- "Review" button posts full form to `#wizard-body` → step 3

**Step 3 — `templates/ParticipationImportResource/step3.html`** (HTMX partial, no layout)
Summary table: scraped name | resolved team | formation | action (create / already exists / skip). Hidden inputs forwarded from step 2. Confirm button: `hx-post="/participations/import/save"` with full-page redirect on 303.

**Navigation:** add "Import from BFU" button/link to existing `ParticipationResource/list.html`.

**CLAUDE.md conventions to observe:**
- Shared nav: `{#appNav username=username /}`
- `referrerpolicy="no-referrer"` on any BFU `<img>` tags
- No `{N}` quantifiers in HTML attributes (Qute parses `{4}` as template expression)
- Pico CSS classless — no additional CSS framework
