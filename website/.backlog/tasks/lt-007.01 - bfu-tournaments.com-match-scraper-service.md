## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Given a bfu-tournaments.com match page URL, scrape it into a raw DTO (mirroring the EbfuMatchLineup/EbfuTeamLineup/EbfuLineupEntry shape from LT-006.01): final score, both sides' full lineups (starters + reserves + shirt numbers), goal scorers with minute, cards (yellow/second-yellow/red) with minute, and substitutions (player in, player out, minute). Follow the Jsoup + checked-exception + fixture-based-test pattern from BfuLeagueScraperService.java and EbfuMatchLineupScraperService.java -- no live network calls in tests, no player/team DB matching here (that stays PlayerMatchingService's job). Since no match-detail fixture exists yet, recon a real finished match page on bfu-tournaments.com first (narrow DOM reads via browser tooling, not outerHTML dumps -- see experiences/bfu-scraping/EXP-20260725-0001.md) to build an accurate hand-written fixture.
<!-- SECTION:DESCRIPTION:END -->
