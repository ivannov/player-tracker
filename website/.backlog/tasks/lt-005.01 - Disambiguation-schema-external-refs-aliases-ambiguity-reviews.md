## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
New migration src/main/resources/db/migration/V3__disambiguation.sql plus new entities model/TeamExternalRef.java, model/PlayerAlias.java, model/AmbiguityReview.java, model/AmbiguityCandidate.java.

team_external_refs scopes a team's raw scraped name by source so re-encountering the same team next season is an exact lookup, not a fresh fuzzy match.

player_aliases is scoped by team_id (the team the name was scraped under), not globally -- a player transferring to a new team is correctly treated as a fresh resolution rather than an auto-match, which matters because two different players can share a common Bulgarian name.

ambiguity_reviews/ambiguity_candidates model the admin inbox item: a raw name that couldn't be confidently resolved, with its ranked candidate players and a resolution outcome once an admin acts on it. This is pure schema/entities -- no service logic or UI in this task, that's LT-005.02 and the daily-scheduler epic respectively.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Appended to V1__create_teams.sql instead of a new V3 file, per CLAUDE.md's pre-production single-migration-file convention (no prior deployment yet). Enabled pg_trgm and vector extensions; added team_external_refs, player_aliases (+ GIN trgm index), ambiguity_reviews, ambiguity_candidates tables and their entities/enums. players.name_embedding vector(768) column added to the migration but intentionally NOT mapped on the Player entity yet -- that belongs to LT-005.03 (Ollama embedding layer), which is when code will actually read/write it; schema-management.strategy=none means the unmapped column is harmless in the meantime. Both docker-compose.yml (dev) and the test Dev Services default image (application.properties) were switched to pgvector/pgvector images since plain postgres images lack the vector extension. Added DisambiguationSchemaTest covering round-trips, the GIN trigram index (% operator), and ON DELETE CASCADE from ambiguity_reviews to ambiguity_candidates. mvn verify: 123/123 tests pass.
