## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a service method that takes a BFU league page URL and returns the list of team names exactly as they appear on the page. This is the data-extraction foundation for the import wizard (LT-001).

Context:
- Project already uses Jsoup for lineup scraping — follow the same pattern
- BFU URLs look like `https://bfu-tournaments.com/leagues/first?season=2024-2025`
- The returned names will be matched against `Team.name` in the DB by the wizard backend (LT-003)
- Service class lives under `com.nosoftskills.lineup.service`
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Given a valid BFU league URL, the service returns a non-empty ordered list of team name strings as displayed on the page
- [ ] #2 Given an unreachable or malformed URL, the service throws a descriptive checked exception (not a runtime NPE)
- [ ] #3 A unit test with a locally captured BFU HTML fixture covers both the happy path and the error path
- [ ] #4 No network call is made during tests (fixture-based)
<!-- AC:END -->
