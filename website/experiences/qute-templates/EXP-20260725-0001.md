## 1. Objective
Add an HTML `pattern="..."` (or any attribute containing a `{N}` regex quantifier) to a Qute template, e.g. a 4-digit year pattern on a date/season input.

## 2. The Trap
Qute treats any `{...}` in template markup as an expression to evaluate. Writing a regex quantifier like `\d{4}` directly in an HTML attribute makes Qute try to parse `{4}` as a template expression, which breaks template compilation or renders garbage instead of the literal regex.

## 3. Abstracted Insight
> **Core Principle:** Never place a bare `{N}` (or `{N,M}`) quantifier inside Qute-rendered markup — express the repetition literally instead, since Qute's `{...}` syntax is not escapable inline the way it is in plain HTML/JS.

## 4. Validated Path
```html
<!-- Avoid -->
<input pattern="\d{4}" />

<!-- Use instead -->
<input pattern="\d\d\d\d" />
```
For longer repetitions, write out the explicit repeated pattern rather than a quantifier shorthand.

## 5. Verification Checklist
- [ ] No `{N}` or `{N,M}` quantifier appears inside any Qute `.html` template.
- [ ] Template renders and compiles without a Qute parsing error.
